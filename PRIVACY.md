# 🔒 Privacy Notice

## Current application behavior

The routed CodeShare prototype does not implement accounts, authentication, server-side collaboration, or persistent documents. Editor text, theme selection, chat messages, and active panel state remain in React state in the current browser tab and are lost on reload.

## External resources

- The sample presence component requests avatar images from `pravatar.cc`.
- The root layout uses Next.js `next/font/google`, which obtains font assets during the build process and bundles them as configured by Next.js.
- Hosting providers may independently process standard HTTP request metadata in their access logs.

## No production privacy boundary

The prototype has no room authorization, private message transport, data retention policy, or server-side isolation. Do not enter confidential source, credentials, customer information, or private conversations under the assumption that they are protected.

## Future data collection

Any future account, AI, analytics, database, or collaboration feature must update this notice before release. Document data collected, purpose, destination, access controls, retention, deletion, provider terms, and consent/user notice.

## Contact

For privacy questions, contact the maintainer through the GitHub profile linked from this repository. Do not include sensitive information in public issues.
