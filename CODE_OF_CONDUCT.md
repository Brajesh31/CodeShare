# Code of Conduct

This project welcomes contributions from people with different backgrounds and experience. Everyone participating in project spaces should help keep them respectful, useful, and welcoming.

## Expected behavior

- Be considerate, patient, and constructive.
- Discuss code and ideas without attacking or demeaning people.
- Respect privacy; do not publish confidential code, credentials, or private chat content.
- Give useful context in feedback and accept good-faith corrections.
- Be clear when a feature is a mock or prototype rather than an implemented service.

## Unacceptable behavior

Harassment, discrimination, threats, intimidation, doxxing, repeated unwanted contact, deliberate disruption, sexualized attention without consent, and retaliation for raising concerns are not acceptable.

## Maintainer response

Maintainers may remove harmful content, pause discussion, or restrict participation to protect contributors and keep project spaces productive. Responses should be proportionate and may range from a warning to temporary or permanent exclusion.

## Reporting

Report conduct concerns privately to the maintainer through the contact method on the `@brajesh31` GitHub profile. Include enough context to understand the issue and avoid unnecessary sensitive information. For security concerns, follow [SECURITY.md](SECURITY.md). If the concern involves the maintainer, use GitHub's platform reporting tools.

This policy applies to repository issues, discussions, pull requests, and other spaces where someone is participating on behalf of the project.
