# 📖 Glossary

| Term | Meaning in this repository |
|---|---|
| CodeShare / CodeCollab | Repository project name and UI branding |
| App Router | Next.js route system implemented under `app/` |
| Editor route | Client workspace at `/editor` |
| contentEditable | Browser editing attribute used by the sample code pane |
| Local state | React state stored only in the current page session |
| Team chat mock | Client-side message list with no transport |
| AI placeholder | Fixed delayed reply that does not call a model |
| Presence mock | Static sample user list and avatar UI |
| Socket.IO experiment | Unreferenced client in `pagebackup.tsx` |
| WSS | Secure WebSocket transport, required for future production collaboration |
| Room authorization | Server-side rule determining who can access a collaboration room |
| NEXT_PUBLIC_ | Next.js environment variable prefix that exposes values to browser code |
