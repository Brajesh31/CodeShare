# Roadmap

This is a directional list for the current CodeShare prototype. It has no delivery dates and does not promise that any item will be implemented.

## Product and quality foundations

- Replace mock “Connected” and user-presence indicators with real session state only after defining a server protocol.
- Add a backend and authenticated collaboration rooms before enabling shared editor/chat data.
- Choose a tested editor component or implement accessible editing and syntax/language behavior.
- Add meaningful tests for workspace state, chat flows, and connection lifecycle.
- Provide loading, error, reconnect, and offline states for future network features.
- Implement a real AI provider integration only with server-side secret handling, explicit user consent, privacy disclosures, and request limits.
- Review responsive layout and keyboard/screen-reader behavior.

## Propose an item

Open an issue describing the user problem, proposed behavior, security/privacy consequences, and compatibility needs. Follow [CONTRIBUTING.md](CONTRIBUTING.md). Priorities may change as the project evolves.
